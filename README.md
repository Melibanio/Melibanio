### 💭 Sobre mim

Curso **Análise e Desenvolvimento de Sistemas** no Senac São Paulo e gosto de transformar ideias em interfaces que funcionam de verdade — do wireframe ao `localStorage` fazendo o papel de banco de dados. Trabalho bem em equipe: a maioria dos meus projetos nasceu de trabalho em grupo, dividindo páginas, revisando código e aprendendo junto.

Hoje estou entre o JavaScript puro e o Angular, testando onde cada abordagem faz mais sentido.
